# DEPI React Graduation Project 🎓

Final graduation project built with **React** as part of the **DEPI program**.  
This project demonstrates modern frontend development practices, clean architecture, and interactive survey features.

---

## 🚀 Features
- Responsive UI with React and Bootstrap
- Survey creation and management
- Question builder with multiple choice options
- Real-time responses and analytics
- Clean project structure for scalability

---

## 🛠️ Tech Stack
- **Frontend:** React, React Router, Bootstrap
- **State Management:** React Hooks / Context API
- **Backend (planned):** ASP.NET Core Web API
- **Database (planned):** SQL Server / EF Core
- **Version Control:** Git & GitHub
